Just DaVinci Resolve, on macOS or Windows. BreakEven is a single Lua file that runs on the scripting engine already built into Resolve. No Python, no account, no internet connection.

Double-click Install Mac.command (or Install Windows.bat). It copies the one file into Resolve's Scripts folder for you. Restart Resolve and open it from Workspace ▸ Scripts ▸ Utility ▸ BreakEven, and it's there for every project after that.

On a Mac, if it says the file can't be opened because it's from an unidentified developer, right-click Install Mac.command, choose Open, then confirm once. After that it runs normally.
